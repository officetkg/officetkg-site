## 座標系

```
X = 平面図の右方向（東）      LOCK
Y = 平面図の上方向（北）      LOCK
Z = 上方向（FL = 0）          今回追加した唯一の次元
単位 = mm
原点 = 平面図 左下（南西）外壁外面の交点
```

### XYの取得方法

承認済み平面図のピクセル座標を投影プロファイル（dark-line detection）で
実測し、一次変換でmmへ換算した。**目視トレースではない。**

```
X_mm = (px_x - 643) × 12.875
Y_mm = (942 - px_y) × 12.875
```

### 縮尺の検証（独立した2つの面積が一致）

| 項目 | モデル | 表記 | 差 |
|---|---|---|---|
| 専有面積（外形 4700 × 8675） | 40.77㎡ | 40.76㎡ | **+0.03%** |
| バルコニー（4700 × 1385） | 6.51㎡ | 6.40㎡ | +1.7% |

2つの独立した面積がともに一致するため、縮尺 12.875 mm/px は確定とみなす。

### Zについて

平面図はZを持たないため、Zのみを新規に与えた。
**Zを与える際にXYは一切変更していない。**

| 項目 | 値 |
|---|---|
| 天井高（居室） | 2450 |
| 天井高（水回り・玄関） | 2200 |
| 建具開口高 | 2000 |
| 掃き出し窓 上端 | 2100 |
| バルコニー床 / 手摺天端 | −150 / +1050 |
| 玄関土間 | −120 |

## 方位（参考案により確定）

KEN図の方位記号を画素実測した結果：

```
円      中心 (1143.5, 1012) / 半径 約22px
上端    y 978-989   円から 12px 突出   ← 長い = 北
下端    y 1036-1041 円から  6px 突出
"N"     y 1045-1053 下端よりさらに下 = 記号全体のキャプション
```

針は**上端の方が長く**、「N」は記号の見出しです。
参考案の方位記号（上向き矢印＋下に「N」）が同じ体裁で、この読みを追認しました。

| 面 | 方位 |
|---|---|
| 平面の上（+Y／共用廊下側） | **N6°E** |
| バルコニー（−Y） | **S6°W**（ほぼ真南向き） |
| キッチン側（+X） | E6°S |

`PLAN_UP_BEARING_DEG = 6.0` として記録。
旧版は方位未確定のまま+Yを便宜的に北としていましたが、実方位との差は6°のため
**XY座標の変更は不要**です。この値はフォトリアル工程の太陽光方向にのみ使用します。

## 参考案（添付案）との相互検証

`python3 crosscheck_reference.py`

参考案は別途レンダリングされた「案」で、**外形の縦横比が承認済みKEN図と6%異なります**
（0.575 vs 0.542）。マスターの縦横比は専有面積・バルコニー面積という
独立した2つの実数値で裏付けられているため、参考案の寸法そのものは採用せず、
**外形で正規化した相対位置のみ**を比較しました。

u = (px - 432) / 476  ->  X_mm = u * 4700
v = (904 - py) / 828  ->  Y_mm = v * 8675

座標の変更は行っていません。

可動収納壁は**L字**。Master Bedroomの**南側**と**東側**の2面が建具で、
南東コーナーで直交する。戸袋はそれぞれコーナーから最も遠い端にある。

| レッグ | 建具ゾーン | 走行範囲（閉時に塞ぐ） | 戸袋 | 枚数 |
|---|---|---|---|---|
| 南北（MBR東側） | X 1975–2095 | Y 2360–4330（1970） | Y 4330–5035（北端） | 3枚×657 |
| 東西（MBR南側） | Y 2290–2360 | X 850–1975（1125） | X 195–850（西端） | 2枚×563 |

固定部は北端の袖壁 Y 5035–5280 のみ。

### 図面からの根拠（画素実測）

```
南北レッグ  建具ライン x=799 (X 2008) / 吊り金物 y 651-654, 696-700
            戸袋(破線) y 551-606   -> Y 4330-5035
東西レッグ  建具ライン y=759,762   -> Y 2318-2356（薄い引戸の二重線）
            戸袋(破線) x 658-709   -> X  195- 850
```

両レッグとも「細い二重線＋吊り金物のティック」で描かれており、
躯体壁の太い塗り潰しとは描き分けられている。
戸袋長さが建具1枚分にちょうど一致する点も両レッグで整合する
（南北 705 ≧ 657／東西 655 ≧ 563）。

> **訂正** — 初版ではこの東西レッグを「MBR南壁」として固定内壁に分類していた。
> 躯体壁ではなく可動建具であり、`WALL_INT` から除外して `MOVABLE_WALL` に移した。

### 常時開放（既定）

`MOVABLE_WALL_STATE = "OPEN"` で両レッグとも戸袋に引き込み、
**南側1125mm・東側1970mmが同時に素通し**となる。
南東コーナーが完全に開き、Master Bedroomは
Living Diningおよび西ベイ（Book Shelf側）と一体の空間になる。

レール・戸袋・袖壁のXYは開閉状態によらず不変。
参考用に `"CLOSED"` へ切り替えれば閉状態も生成できるが、
**既定は常時開放**であり、室内パースもこの状態で撮影する。

## 承認後の手順（GEOMETRY APPROVED後）

新しいシーンは作らず、`out/soho1415_master.glb`（または
`blender_build.py` が生成する同一座標の`.blend`）に
**カメラだけを追加**して撮影する。

| カメラ | 位置・方向 |
|---|---|
| CAMERA 1 | バルコニー側 → 入口方向 |
| CAMERA 2 | 入口側 → バルコニー方向 |
| CAMERA 3 | 6人用ミーティングテーブル付近 → 2人用ワークスペース方向 |
| CAMERA 4 | ワークスペース → Living Dining方向 |

カメラ高 1500–1600mm 相当 / フルサイズ換算 28–35mm / 超広角禁止。

同一モデルの別カメラレンダリングであるため、壁が増える・Book Shelfが変わる・
ベッドが出現する・家具が移動する・部屋が広くなることは構造上起こらない。
ベッドルーム間仕切壁もL字・常時開放のまま固定される。

最終工程でAIを使うのは **材質・光・質感・フォトリアリズムのみ**。
AIによるgeometry変更は禁止。
